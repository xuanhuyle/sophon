# Evidence gate: one public matched system for the governance-integrity lifecycle test

Date of investigation: 2026-10-11. Three candidate systems were inspected from primary files and commits
(cloned with history into a scratch directory; nothing was taken from project marketing). Network from this
container reaches GitHub (git and raw files), the npm registry and PyPI only. Every French government host
(legifrance.gouv.fr, urssaf.fr, service-public.fr, data.gouv.fr, echanges.dila.gouv.fr) and nyc.gov were
unreachable both from the container and from the web-fetch tool (DNS failure or proxy 403). This shaped what
counts as "authentic governing text" below, and the limitation is recorded rather than worked around.

## Gate outcome

**PARTIAL / LIMITED.** Candidate 3 (betagouv/mon-entreprise with its Publicodes rule library, governed by the
French Code de la sécurité sociale) satisfies A, C, D and E and satisfies B only in the sense of "the
organisation's own executable semantic definitions". It is **not** a dbt MetricFlow / Snowflake / Databricks
semantic layer and there is no warehouse: the data the semantic layer "already exposes" is the computed output
of the rule engine for a declared situation. Candidates 1 and 2 fail A and D outright. Under the prompt's rule
this permits building only the narrow capability that can genuinely be checked (deterministic, numerically
verifiable requirements), and the result is **ineligible for a full-thesis CONTINUE** whatever it shows.

### Downstream consumption evidence

The rule library is consumed by the mon-entreprise simulators and its public API (`api/` in the repo, e2e
tests under `api/source/test-e2e/` changed in `8d04dbb65`). No BI tool or AI agent consumer exists. T5 (thin
consumer) can at most call the published library the way the API does; it cannot show agent compliance.

### Every missing element

1. **No BI / warehouse semantic layer.** Publicodes rules are executable semantic definitions, not dbt
   MetricFlow or a Snowflake/Databricks semantic view. There is no data estate; "execution against data" means
   evaluating the engine for declared situations. Criterion 6 of the success rule ("real native semantic
   execution against data") is therefore satisfiable only in this weaker sense.
2. **Decree texts not retrievable.** Légifrance, URSSAF, service-public, DILA open data and mirrors were all
   unreachable. The governing corpus is the consolidated code article text with its legal dates and LEGI's
   modification links. Preambles, transitional provisions and the decree's own wording are unavailable.
3. **URSSAF explanatory pages cited by the rules are unreachable.** Rules reference
   `urssaf.fr/.../reforme-cotisations-independants.html`; the oracle cannot use them.
4. **No legal sign-off exists anywhere.** PR approvals (JalilArfaoui approved #4101 on 2025-12-08) are
   engineering approvals. Issue #4294's "Source : Urssaf" label and "retours métier" are informal business
   validation. The experiment records "no approval recorded" where that is the truth.
5. **PR metadata came from HTML.** GitHub's API was blocked (403). Opened/merged dates, SHAs, reviewers and
   comments were read from the public PR and issue pages on 2026-10-11; exact ISO merge timestamps are not
   available.
6. **The independent oracle is partial.** OpenFisca-France encodes the micro-social rates (E1, E2) and some
   decree-2024-688 retirement rates, but not the whole reformed base. Where OpenFisca is silent, the oracle is
   the consolidated article text plus hand-checkable arithmetic; where neither settles the meaning, the label
   is UNRESOLVED.
7. **Candidate 3's authors are not blind to this experiment's existence, but they wrote everything before
   it.** No fixture was authored after reading a future change. All pre-change inputs are published artifacts
   dated before the change they precede.
8. **One organisation, two repos.** The governing corpus (DILA/Légifrance) and the semantic implementation
   (URSSAF/beta.gouv) are different public bodies. This is a law-to-executable-rules pair, which the prompt
   explicitly names as narrower than the semantic-layer hypothesis.

## Consequence for scope

- Scored requirements: deterministic numeric provisions with an independent reference (rates, dates,
  thresholds: D613-4 rows, D136-5 floor and ceiling, L136-3 26 %, D621-2 formula constants, D131-6-1 Acre
  thresholds). Everything else in the touched articles is COVERAGE-classified and left unscored.
- Full-thesis CONTINUE is not available from this gate. The best achievable positive result is a bounded,
  limited one on a law-to-rules system; the worst is a stop of the kernel idea.
