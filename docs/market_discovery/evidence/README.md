# Evidence folder for the market discovery report

Everything the report in `../MARKET_DISCOVERY.md` leans on is in this folder, so that a reader can trace each claim without access to the session that produced it.

| Path | What it is |
|---|---|
| `clusters/*.json` | Fifteen domain-sweep results, one per cluster. Each file holds the finder's result (`found`: workflows, A-to-H estimates, settlement-loop items, sources, blocked URLs) and the adversarial verifier's result (`verification`: refuted, weakened, confirmed, conflations, corrected verdicts). |
| `digest_of_domain_sweeps.md` | Condensed table of the fifteen clusters (finder verdict vs verifier-corrected verdict, volume, review rate, A-to-H, settlement loop, existing solutions), generated by `digest.py`. |
| `stage2/rank_shortlist.json` | The ranking pass: executive call, rationale, eight shortlisted workflows each graded on the brief's 17 dimensions, top three, wedge candidates, hypotheses H1 to H8, rejected domains. |
| `stage2/dive_1.json`, `dive_2.json`, `dive_3.json` | Deep dives on the top three (customs classification, PSP merchant onboarding, mortgage scenario desk) with the twelve section-10C fields. |
| `stage2/refute_1.json`, `refute_2.json`, `refute_3.json` | Adversarial refutations of each deep dive, with corrected verdicts. |
| `stage2/design_D-E-F-G-H.json` | Wedge, competitive threat, research gaps, discovery sprint and base-rate experiment design. |
| `stage2/review_design.json` | Methodology review of the design (gates refuted, missing metrics, access constraints). |
| `stage2/write_draft_v1.md` | The first synthesised draft of the report. |
| `stage2/critique_draft.json` | The completeness and discipline critique of that draft (missing content, discipline violations, factual errors, conflations, hedging, concrete fixes). |
| `cross_recomputation.py`, `cross_recomputation_output.txt` | Independent recomputation of every CBP CROSS statistic quoted in the report from the 216,164-row open-source scrape (`cbp_rulings_data.csv` at https://github.com/justinmoonjeli/CROSSFetch), with the exact definitions used. |
| `stage1_workflow.js`, `stage2_workflow.js`, `digest.py` | The orchestration scripts, kept so the method is inspectable. |

Provenance rules applied throughout: every number carries a URL and a source type in the cluster files; search-snippet figures are marked as snippets; recalled figures are marked `[RECALL, unverified]`; the WebSearch quota ran out partway through the first sweep and every verifier, deep dive, refutation, design, review, draft and critique ran with zero searches and with the egress proxy denying every non-GitHub host.
